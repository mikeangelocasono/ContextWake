# Documentation assets

- `contextwake-hero.svg` is the repository-owned README banner. It uses no third-party logos or artwork.
- `contextwake-tui.svg` is a vector rendering of a real 120 x 36 ContextWake terminal frame captured from `ctx 0.1.0-alpha.2` against a disposable dirty Git repository. Only the local filesystem path and fixture directory name were replaced with `demo-app`; provider status, Git counts, layout, and application copy came from the running binary.
- `contextwake-tui.png` is the browser-rendered PNG used by the README.
- `contextwake-social-preview.svg` and `.png` are repository-owned 1280 x 640 social-preview artwork. The compact terminal card is illustrative brand artwork, not a product screenshot or provider response.

The social-preview PNG must be uploaded manually in GitHub repository settings unless a supported authenticated repository API is available. Do not add account identifiers, private paths, provider logos, or fabricated provider output to these assets.
