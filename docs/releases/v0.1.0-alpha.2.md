# ContextWake v0.1.0-alpha.2

This alpha significantly expands ContextWake's terminal coding-agent ecosystem
while making `ctx` the canonical command and preserving `ctxwake` as a
compatibility alias. Both entrypoints use the same application services and
keep the `contextwake` package identity, `.contextwake` project configuration,
`CONTEXTWAKE_HOME`, and SQLite state.

## Highlights

- Short `ctx` command for the dashboard, diagnostics, profiles, workspaces,
  sessions, checkpoints, and handoffs.
- Compatibility `ctxwake` executable with the same version and behavior.
- Release archives contain both native binaries plus README and LICENSE.
- First-class GitHub Copilot CLI, Cursor CLI, Kimi Code, and Grok Build
  adapters alongside the five existing adapters.
- Ordered capability-driven registry, bounded parallel discovery, reusable
  shell-free ACP transport, and shared bounded provider probes.
- Scrollable/filterable nine-agent TUI, expanded doctor output, provider
  guides, contributor guide, and evidence-based compatibility matrix.
- Deterministic AWHF matrix covering seven representative cross-agent hops and
  dirty Git state without requiring provider credentials.

## Provider status

Codex, Claude Code, GitHub Copilot CLI, Cursor CLI, OpenCode, Gemini CLI, Kiro
CLI, Kimi Code, and Grok Build are registered adapters. Cursor and Grok Build
received live Windows detection/interface QA. Copilot and Kimi are contract
tested but were not installed on the QA host. Capabilities remain partial where
authenticated or cross-platform provider QA is unavailable. Cross-agent
continuity is represented as a portable handoff, never as native transcript
transfer.

## Platform and security notes

Windows and macOS alpha binaries are unsigned; the macOS artifact is not
notarized. Verify `SHA256SUMS`, keep platform protections enabled, and review
the current [limitations](../../README.md#current-limitations) before use.

This project does not bypass provider quotas, rate limits, subscription
restrictions, authentication controls, or Terms of Service.
